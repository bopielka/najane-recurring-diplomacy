# Recurring Diplomacy by Najane

A UI mod for Civilization VII that keeps the diplomatic agreements you choose running. Open
Borders, Research Collaboration, Counterspy and the other timed treaties and endeavours last a set
number of turns; when one you have marked runs out, the mod proposes it again at the start of your
turn — through the same action you would use on the Diplomacy screen, at the same Influence price.

**No rules change.** The other leader can still refuse, and nothing is proposed that you did not
switch on. Your choices are kept in the save itself, so loading an older save brings back the
choices that save had.

**Status: 1.2** — the sync toggle beside each treaty, endeavour, espionage action and sanction, the game's
instance limits (Shift+click moves a full one), renewal at the start of your turn and a summary
toast coloured by each leader's answer. Not yet: the Influence reserve and options. Details in
[`documentation/01-what-the-mod-does.md`](documentation/01-what-the-mod-does.md).

## Deploy

```bash
./deploy.sh
```

Then enable the mod in *Additional Content → Mods* (a new mod is not enabled by default) and return
to the main menu or restart. `Logs\UI.log` shows `najane-recurring-diplomacy: loaded, build …`.

## Layout

| Path | What |
|---|---|
| `najane-recurring-diplomacy.modinfo` | mod manifest |
| `ui/` | the mod's scripts (`recurring-diplomacy.js` is the entry point) |
| `text/<locale>/` | localisation: `en_us`, `de_DE`, `es_ES`, `fr_FR`, `it_IT`, `ja_JP`, `ko_KR`, `pl_PL`, `pt_BR`, `ru_RU` (Ukrainian - see the file), `zh_Hans_CN`, `zh_Hant_HK` |
| `icons/` | deployed images (`sync.png`), generated by `tools/make-icons.py` from `assets/` |
| `documentation/` | developer documentation, start at its `README.md` |
| `game-files-snapshots/` | copies of the game files the mod depends on; never deployed |
| `steam-description.bbcode` / `STEAM_CHANGELOG.bbcode` | Workshop page and change notes |
